# SDLC Canonical Pack

This pack adds reusable SDLC paperwork, project-start questions, and launch/readiness checklists beside the existing local product-specific SDLC note.

Structure:

- `UPSTREAM_SOURCES.md`: provenance and license notes
- `LICENSES\`: copied license files when clear
- `templates\`: sparse upstream docs and local reusable templates
- `summaries\`: short routing notes
- `checks\`: local gate and readiness checklists
