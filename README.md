# Software Development Lifecycle Files

This folder is a source shelf of blank SDLC templates, reusable checklists, and pinned SDLC packs. It should stay reusable and not become the filled record for a specific build.

Use order:

1. Read `Software development life cycle..txt` when the task is EARP-specific.
2. Read `00-github-canonical-pack\README.md`.
3. Copy the needed SDLC template into the active project.
4. Fill in the project copy there, not here.
